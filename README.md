# FixLab — симулятор мастерской

Браузерная игра на чистых **HTML, CSS и JavaScript**. Не нужны npm, серверная часть или API-ключи. Все изображения смартфонов лежат локально в `assets/phones/`, поэтому каталог не зависит от сторонних фотохостингов.

## Запуск

1. Скачай ZIP и распакуй папку `fixlab-game`.
2. Открой `index.html` в современном браузере.
3. Начни с покупки телефона на рынке.

Для разработки можно открыть папку в VS Code и запустить `index.html` через Live Server, но для самой игры это необязательно.

## Как играть

1. Выбери неисправный телефон. В карточке и подробностях видны цена покупки, стоимость запчасти, цена продажи и ожидаемая награда мастеру.
2. Купи устройство — деньги спишутся с баланса, телефон появится на верстаке. Одновременно можно ремонтировать один телефон.
3. Проведи бесплатную диагностику.
4. Подбери правильную запчасть. Неверный выбор не списывает деньги.
5. Установи деталь — стоимость запчасти спишется с баланса.
6. Продай исправный телефон и получи оплату за устройство плюс награду за работу.

## Как начисляются деньги

Награда за ремонт не фиксированная. Она зависит от цены запчасти и сложности работы:

```js
награда = округлитьДо50(стоимостьЗапчасти × 0.9 + сложность × 250)
чистаяПрибыль = ценаПродажи + награда − ценаПокупки − стоимостьЗапчасти
```

Например, замена аккумулятора приносит меньшую награду, чем сложная замена дисплея или шлейфа датчиков. Чем дороже и сложнее ремонт, тем выше выплата. Вместе с деньгами начисляются XP и репутация; XP за ремонт также зависит от сложности.

Баланс, опыт, репутация, избранное и текущий этап ремонта сохраняются в `localStorage`. Сохранения предыдущей версии игры автоматически подхватываются.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи **содержимое** этой папки: `index.html`, `styles.css`, `game.js`, `README.md`, `.nojekyll` и папку `assets`. `index.html` должен находиться в корне репозитория.
3. В репозитории открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. После публикации GitHub Pages покажет адрес сайта в том же разделе.

## Настройка

- Каталог, цены, неисправности и детали: массив `catalog` в `game.js`.
- Стартовый баланс: `INITIAL_BALANCE` в `game.js`.
- Формула награды: `getRepairReward()` в `game.js`.
- Опыт за ремонт: `getXpReward()` в `game.js`.
- Внешний вид и адаптивность: `styles.css`.

Все цены, лоты и характеристики — условные игровые данные. Это не реальный магазин и не платформа для покупок.
